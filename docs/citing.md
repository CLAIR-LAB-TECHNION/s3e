# Citing s3e

If you use `s3e` in your research, please cite the S3E paper:

```bibtex
@inproceedings{azran2025s3e,
  title     = {{S3E}: Semantic Symbolic State Estimation With Vision-Language Foundation Models},
  author    = {Azran, Guy and Goshen, Yuval and Yuan, Kai and Keren, Sarah},
  booktitle = {Workshop on Planning in the Era of LLMs (LM4Plan) at the AAAI Conference on Artificial Intelligence},
  year      = {2025},
  url       = {https://openreview.net/forum?id=gw4hYNFUIC}
}
```

The repository's
[`CITATION.cff`](https://github.com/CLAIR-LAB-TECHNION/s3e/blob/main/CITATION.cff)
describes both the paper and the software itself (title, authors, version,
license). GitHub's "Cite this repository" button and reference managers that
read CFF files use it. When you report results, also give the `s3e` version
you used (`s3e.__version__`), since behavior can change between minor versions
before 1.0 (see the {doc}`changelog`).

## Publications

`s3e` is the reference implementation of the S3E method, introduced in the
paper above.

If you use `s3e` in a publication, please let us know by
[opening an issue](https://github.com/CLAIR-LAB-TECHNION/s3e/issues/new/choose)
so we can list it here.
